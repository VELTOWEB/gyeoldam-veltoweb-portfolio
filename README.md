# GYEOLDAM / 결담 — VELTOWEB Portfolio

정적 HTML/CSS/Vanilla JavaScript로 제작된 6페이지 프리미엄 다이닝 포트폴리오입니다.

## 실행
- `index.html`을 Live Server로 열거나 GitHub Pages에 그대로 업로드하세요.
- 별도 빌드/서버 설치가 필요 없습니다.

## 페이지
- HOME / MENU / STORY / SPACE / RESERVATION / VISIT

## 이미지
- 포트폴리오 데모용으로 Pexels의 공개 이미지 CDN을 사용합니다. 네트워크 연결이 있어야 사진이 표시됩니다.
- 실제 상업 배포 전에는 동일 톤의 자체 촬영/생성 이미지로 `assets/js/data.js`와 각 HTML의 이미지 URL을 교체하는 것을 권장합니다.

## 주의
- GYEOLDAM은 VELTOWEB 포트폴리오용 가상 브랜드입니다.
- 예약 기능은 프론트엔드 데모이며 실제 예약을 전송하지 않습니다.
